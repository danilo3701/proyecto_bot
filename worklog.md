**Режим 0 (Chat 0) = PROMPT NORMALIZER**
- Я пишу свободно
- Ассистент возвращает только PROMPT (normalized) без гипотез/вопросов/решений

**Режим A (Chat A) = DIAGNOST**
- Вход: PROMPT (normalized) + логи/скрины + контекст
- Выход: где сломано и что проверить (1–3 точки), без патча

**Режим B (Chat B) = PATCH**
- Вход: результат диагностики (A)
- Выход: точные правки (Файл → функция → якорь → 🔁/➕/🧹), 1:1
